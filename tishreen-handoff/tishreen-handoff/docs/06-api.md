# 06 — REST API Contract (`/api/v1`)

Spring Boot 3, JSON only, UTF-8. OpenAPI generated by springdoc at `/api/v1/docs` (dev/IT only).
Entities never leave the service layer — every endpoint speaks DTOs (records). Field names `camelCase`.

## 1. Conventions

### Auth
- `Authorization: Bearer <accessToken>` (JWT HS256, 30 min, claims: `sub`=userId, `role`, `status`, `lang`, `perms[]`).
- Refresh token: HttpOnly, Secure, SameSite=Lax cookie `tishreen_rt` (JWT, 7 days, rotated on each refresh; claim `pv` = password-version derived from `password_hash` prefix so a password change invalidates it).
- `BLOCKED` users: login `403 USER_BLOCKED`; existing access tokens are rejected by `JwtAuthFilter` which re-checks `users.status` from a 60s cache.
- Authorization: `@PreAuthorize("hasAuthority('ORDER_MANAGE')")` on controller methods; customer endpoints use `hasRole('CUSTOMER')` + ownership in the service (`404` when not owner).

### Language
- `Accept-Language: ar|en` (default `ar`). Localized DTO fields (`name`, `description`) are resolved with Arabic fallback. Admin DTOs expose both `nameAr`/`nameEn`.
- Error messages are localized from `messages_ar.properties` / `messages_en.properties`.

### Errors (always this shape)
```json
{ "code": "ORDER_INVALID_TRANSITION", "message": "لا يمكن نقل الطلب من هذه الحالة", "details": { "from": "NEW", "to": "DELIVERED" }, "correlationId": "8f2c…" }
```
| HTTP | When |
|---|---|
| 400 | malformed request, `OTP_INVALID`, validation (`details.fields[{field, code}]`) |
| 401 | missing/expired token, `AUTH_BAD_CREDENTIALS` |
| 403 | permission denied, `USER_BLOCKED`, `ACCOUNT_NOT_ACTIVE` |
| 404 | not found or not owned |
| 409 | conflicts: `USER_PHONE_EXISTS`, `ORDER_INVALID_TRANSITION`, `SLUG_EXISTS`, `OFFER_ALREADY_APPLIED` |
| 410 | `OTP_EXPIRED` |
| 422 | business rule: `PRODUCT_UNAVAILABLE`, `BELOW_MIN_ORDER`, `PICKUP_TIME_INVALID`, `ZONE_INACTIVE`, `POINTS_INSUFFICIENT`, `WEIGHT_STEP_INVALID`, `REASON_REQUIRED`, `OFFER_CONDITION_UNKNOWN`, `THEME_CONTRAST_FAILED`, `THEME_PRESET_INVALID` |
| 423 | `STORE_CLOSED`, `OTP_LOCKED` |
| 429 | rate limit (`Retry-After`) |
| 500 | never leaks stack traces; logged with `correlationId` |

### Pagination & sorting
`?page=0&size=20&sort=createdAt,desc` → 
```json
{ "content": [...], "page": 0, "size": 20, "totalElements": 135, "totalPages": 7 }
```
`size` max 100. Every list endpoint is paginated and backed by an index (see `02-data-model.md §14`).

### Headers
- `X-Correlation-Id` (in/out), `Idempotency-Key` (driver/staff mutating actions), `ETag`/`If-None-Match` on `/home`, `/theme`, `/categories`.

### Common DTOs
```ts
Money = string  // "180000.00" (BigDecimal as string to avoid float loss)
Qty   = string  // "1.250"
LocalizedText = string            // resolved
Bilingual = { ar: string, en?: string }
UserSummary = { id, fullName, phone, role, status, preferredLanguage }
ProductCard = { id, slug, name, unit: 'KG'|'PIECE', price: Money, imageUrl?, thumbUrl?, isAvailable, categoryId }
ProductDetail = ProductCard & { description?, images: [{url, thumbUrl, isPrimary}], options: [{id, name, priceDelta: Money}], weightStep?: Qty, minQty: Qty }
OrderItemDto = { id, productId, name, unit, unitPrice: Money, requestedQty: Qty, actualQty?: Qty, option?, lineTotal?: Money, note? }
OrderDto = { id, orderNumber, status, fulfillmentType, lang, pickupTime?, addressSnapshot?, deliveryLat?, deliveryLng?, zone?: {id, name}, deliveryFee: Money, subtotal: Money, discountTotal: Money, pointsRedeemed, finalTotal?: Money, estimatedTotal: Money, paymentStatus, customerNote?, cancelReason?, items: OrderItemDto[], history: [{from?, to, at, by?, note?}], createdAt, updatedAt, whatsappUrl? }
```

## 12. Security checklist per endpoint (enforced in code review)
- Customer endpoints: service loads by `(id, customerId = current)` → `404` otherwise.
- Driver endpoints: `deliveries.driver_id = current` → `404` otherwise.
- Every mutating endpoint validates its DTO (`@Valid`) and maps to a business exception (`422`) — never a raw `DataIntegrityViolationException`.
- File uploads: content sniffing (magic bytes), size limit, re-encode to WebP.
- CORS: only the web origin(s) from `app.cors.origins`; credentials allowed (refresh cookie).
- Headers: `X-Content-Type-Options`, `X-Frame-Options: DENY`, `Referrer-Policy`, CSP for `/media`.
