# 10 — Internationalisation (ar default · en secondary)

## 1. Principles
1. **No literal UI text in components.** Every string is `t('key')`. Hook `check-frontend-rules` flags Arabic letters or quoted English sentences inside JSX.
2. `ar.json` is complete; `en.json` may lag — i18next `fallbackLng: 'ar'`.
3. Database content is bilingual by columns; the **service layer** resolves `name = name_en ?? name_ar` per `Accept-Language`. Components never do `?? nameAr`.
4. Direction follows language: `ar → dir="rtl"`, `en → dir="ltr"`, set on `<html>` in `__root.tsx`; persisted in `localStorage('tishreen.lang')` and `users.preferred_language` when logged in (`PATCH /me`).

## 3. Formatting helpers (`src/lib/i18n/format.ts`)
- `formatMoney(amount: string, lang)` → `Intl.NumberFormat(lang === 'ar' ? 'ar-SY-u-nu-latn' : 'en', { maximumFractionDigits: 0 })` + currency label from `common.currency`. Western digits by default (`nu-latn`); a future setting may switch to `nu-arab`.
- `formatQty(qty, unit, lang)` → `1.250 كغ` / `2 قطع`.
- `formatDate(iso, lang)` → `Intl.DateTimeFormat` with `timeZone: 'Asia/Damascus'`.
- `formatRelative(iso)` for queue ages ("منذ 4 دقائق").

## 4. Backend messages
`messages_ar.properties` (default) / `messages_en.properties`: keys = error codes (`ORDER_INVALID_TRANSITION=لا يمكن …`) and notification templates (`order.update.CONFIRMED=استلمنا طلبك #{0} وسنبدأ تحضيره`, `otp.activation=مرحبًا {0}، كود تفعيل حسابك…`). `LocaleResolver` reads `Accept-Language`; notifications use the **recipient's** language (`users.preferred_language` / `orders.lang`), not the caller's.

## 5. Slugs
Latin, lowercase, hyphens; generated from `name_en` when present else transliterated from `name_ar` (simple map) with numeric suffix on conflict; always editable by admin; immutable once a product has orders (redirect table not needed at this scale — keep old slug).

## 6. Checklist per screen
- [ ] All strings via `t()`; keys exist in `ar.json`.
- [ ] Renders in `dir=rtl` and `dir=ltr` without overflow.
- [ ] Numbers/phones isolated with `<bdi>`/`dir="ltr"`.
- [ ] Dates/money through the helpers.
- [ ] Error codes covered in `errors.*`.
