# Schema map (authoritative DDL: tishreen-handoff/tishreen-handoff/docs/03-schema.sql — validated; column spec: tishreen-handoff/tishreen-handoff/docs/02)

**identity (8)**: `roles(code)` · `permissions(code)` · `role_permissions` · `users(full_name, phone UNIQUE, password_hash, role_id, status, preferred_language, last_login_at, is_active)` · `customer_profiles(user_id 1:1)` · `employee_profiles(job_title, hired_at, notes)` · `driver_profiles(vehicle_type, vehicle_plate, is_available)` · `otp_codes(user_id, code_hash, purpose, expires_at, attempts, consumed_at)`.
**geo (2)**: `delivery_zones(name_ar/en, fee, min_order, is_active, sort_order)` · `addresses(user_id, label, zone_id, details, latitude, longitude NUMERIC(9,6) NULL, is_default)` — partial unique default per user.
**catalog (5)**: `categories(parent_id, slug UNIQUE, sort_order, is_active)` · `products(category_id, slug UNIQUE, unit KG|PIECE, price, cost_price, stock_cached NUMERIC(12,3), low_stock_threshold, is_available, is_active, version)` · `product_options(product_id, price_delta)` · `product_images(product_id, image_key, is_primary partial-unique)` · `faq_entries` (support).
**ordering (6)**: `orders(order_number T-…, user_id, fulfillment_type, status, address_snapshot JSONB, delivery_zone_snapshot, delivery_lat/lng, pickup_time, subtotal_estimate, discount_amount, delivery_fee, points_redeemed, points_discount, final_total, customer_language, customer_note, cancel_reason, version)` · `order_items(product snapshot: name_ar/en, unit_price incl. option delta, option_name, requested_qty, actual_qty, line_total)` · `order_status_history(from, to, actor, note)` · `payments(method COD, amount, recorded_by, idempotency_key)` · `offer_redemptions(order_id, offer_id, discount_amount)` · `notification_log(user_id, type, channel, status, payload, sent_by)`.
**delivery (1)**: `deliveries(order_id UNIQUE, driver_id, attempts, failure_reason, collected_amount, delivered_at)`.
**loyalty (2)**: `points_transactions(user_id, type, points, order_id, reason, expires_at)` · `offers(scope PUBLIC|TARGETED, conditions JSONB, benefit_type PERCENT|FIXED|FREE_DELIVERY|BONUS_POINTS, benefit_value, applies_to CART|PRODUCT|CATEGORY, target_id, valid_from/to, usage_limit_total, usage_limit_per_customer, is_active)`.
**support (3)**: `support_tickets(ticket_number S-…, user_id, kind CUSTOMER|TECH, status, assigned_to)` · `ticket_messages(is_internal)` · `faq_entries(question/answer ar/en, keywords TEXT[], sort_order)`.
**inventory (4)**: `suppliers` · `purchase_invoices(supplier_id, invoice_date, total)` · `purchase_items(product_id, qty, unit_cost)` · `stock_movements(product_id, type, qty, reason, order_id, purchase_item_id, actor)`.
**cms (2)**: `theme_settings(key PK, value, type COLOR|IMAGE|TEXT|FONT)` · `content_blocks(block_type, title, payload JSONB, sort_order, is_active, starts_at, ends_at)`.
**platform (2)**: `settings(key PK, value, group_name BUSINESS|TECHNICAL|PROVIDERS)` · `audit_log(actor_id, actor_role, action, entity_type, entity_id, old_value JSONB, new_value JSONB, ip, correlation_id)`.

**Conventions**: `id BIGINT IDENTITY`, `created_at/updated_at TIMESTAMPTZ` (trigger `set_updated_at`), `is_active` soft delete, FKs `ON DELETE RESTRICT`, statuses `VARCHAR + CHECK`, money `NUMERIC(14,2)`, qty `NUMERIC(12,3)`, JSON `JSONB`. Views: `v_stock_balance`, `v_points_balance`. Sequences: `order_number_seq`, `ticket_number_seq`.
**Conditional CHECKs**: DELIVERY orders need `address_snapshot` + `delivery_zone_snapshot`; PICKUP needs `pickup_time`; lat/lng both null or both set; `WASTE`/`ADJUSTMENT` movements need `reason`; `ADJUST` points need `reason`; `CANCELLED` needs `cancel_reason`.
**Indexes that must exist** (02 §14): orders(user_id, created_at desc), orders(status, created_at), order_items(order_id), deliveries(driver_id, created_at), points_transactions(user_id), stock_movements(product_id), products(category_id, is_active), products lower(name_ar) trigram, audit_log(entity_type, entity_id), audit_log(created_at), notification_log(status), support_tickets(status, assigned_to).

**Never**: balance columns (except the derived `stock_cached`), UPDATE/DELETE on ledgers or audit, enums, floats, hard deletes, cross-module joins for historical display (use snapshots).
